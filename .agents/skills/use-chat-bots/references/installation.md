# Local installation

Default project: `C:\Users\User\Documents\ChatGPT\MultiChatAgent`

Default Python executable: `C:\Users\User\Documents\ChatGPT\MultiChatAgent\.venv\Scripts\python.exe`

The installer replaces this reference in the installed skill with the actual absolute paths. If the interpreter is absent, run the project bootstrap before sending jobs. If the checkout moves, reinstall the skill and native host from its new location.
