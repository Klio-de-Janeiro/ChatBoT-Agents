MultiChat Agent

Расширение использует текущий профиль Chrome. Сначала вручную войдите в нужный сервис и оставьте его вкладку открытой. Для каждой роли будет создана отдельная неактивная вкладка.

Разрешённые сервисы

Селекторы зависят от версии сайта. Если DOM не распознан, расширение остановится. Перед изменением проверьте элементы в DevTools; CSS для роли assistant должен выбирать только ответ, а complete — его явное состояние завершения. 


    

      Не повторяйте неизвестный запрос под новым ID до ручной проверки. Состояния запросов
      сохраняются; удаление расширения или очистка его данных удаляет защиту от повторов.
